### Task 1: Debug the weather fetcher

A junior developer wrote weather.py to fetch current weather from the free Open-Meteo API and save it as JSON, however the code contains several errors. Your job is to find all five bugs by inspecting both the code and its output, then commit corrected code.

### Task 2: Build the weather collector
Using your corrected weather.py from Task 1 as an import, create a new Python file called collector.py with three functions that collect weather for a list of cities, merge results into a historical log and report basic statistics.  A fourth function called will also be included that tests the correctness of your previous three functions

### Task 3: Generate the weather report
In this task you will create a simple HTML page that displays the weather results produced in Task 2.
